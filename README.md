# Big Number Multiplier 🔢

A simple Python program that multiplies **very large integers** accurately using Python’s built-in arbitrary-precision integer support.

This project demonstrates how Python can handle numbers that have very large digits.

---

## 🚀 Features

- Multiplication of extremely large numbers
- User input via command line
- Works fully offline
- Compatible with Python 3
- Clean and readable code structure

---

- Python 3.x
